# 한능검 기출 웹앱 — 사용법

## 처음 한 번

```
cd "01. 프로그래밍\\\\\\\\05. 한능검 기출 웹앱"
pip install -r requirements.txt
python -m playwright install chromium      (테스트를 돌릴 때만 필요)
```

그다음 `웹앱\\\\\\\_빌드.bat` 을 더블클릭하면 `dist\\\\\\\\index.html` 이 생긴다. 이 파일을 브라우저로 연다.

## 새 시험지 추가

1. 문제지와 정답표 PDF 를 `inbox\\\\\\\\` 에 넣는다. 파일명에 `78회` 처럼 회차가 있고,
문제지에는 `문제`, 정답표에는 `정답`(또는 `답지`) 이 들어 있어야 한다.
2. `새시험지\\\\\\\_추가.bat` 실행.
3. `data\\\\\\\\78\\\\\\\\문항.csv` 를 엑셀로 열어 `검토필요=Y` 문항의 시대를 확인하고 Y 를 지운다.
4. `data\\\\\\\\rounds.csv` 에 시행일을 적는다 (비워도 동작).
5. `웹앱\\\\\\\_빌드.bat` 실행.

스캔(이미지) PDF 는 문항 위치를 못 찾아 자동으로 건너뛴다.

## 해설 추가

1. 해설 PDF 를 `inbox\\\\\\\\해설\\\\\\\\` 에 넣는다. 본문에 `75회 5번` 형식이 있어야 한다. 앞의 큰 번호는 무시된다.
2. `해설\\\\\\\_추가.bat` 실행. 이미 해설이 있는 문항은 건너뛴다 (덮어쓰려면 `python src\\\\\\\\import\\\\\\\_explanations.py --force`).

해설을 직접 고치려면 `문항.csv` 의 해설 칸을 엑셀에서 수정하고 `웹앱\\\\\\\_빌드.bat` 을 실행한다.

## 기록 백업

기록은 이 PC 의 이 브라우저에만 저장된다. 회차 화면 아래의 "백업 파일 받기"로 JSON 을 받아 두고,
다른 기기에서는 "백업 불러오기"로 합친다 (같은 기록은 중복되지 않음).
단일 HTML 테스트본(ver2)에서 쌓은 기록은 주소가 달라 자동으로 보이지 않을 수 있다 — 그때도 백업으로 옮긴다.
